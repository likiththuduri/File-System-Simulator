# File System Simulator in C

## Project Description
A menu-driven File System Simulator developed using the C programming language. It demonstrates file allocation techniques and basic file permission management.

## Features
- Create and delete files
- Write and read file contents
- Contiguous allocation
- Linked allocation
- Indexed allocation
- Display file information
- Display virtual disk blocks
- Set file permissions
- Check read, write, and execute permissions

## Technologies Used
- C Programming
- Structures
- Arrays
- Functions
- String Handling
- Operating Systems Concepts

## How to Compile and Run

Compile using GCC:

bash
gcc -std=c11 -Wall -Wextra -pedantic filesystem.c -o filesystem


Run on Windows:

powershell
.\filesystem.exe


Run on Linux:

bash
./filesystem


## Note
This project simulates file allocation and permissions in memory. File information and content are not permanently stored after the program exits.
